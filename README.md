## writingcontrol.org

Notes from a writing life under construction.

A literary site for fiction and literary-nonfiction projects, and a working dogfood of the [deskwork](https://github.com/audiocontrol-org/deskwork) editorial plugin.

Sister to:
- [audiocontrol.org](https://audiocontrol.org) — open source audio tools
- [editorialcontrol.org](https://editorialcontrol.org) — building with AI agents

### Development

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # → dist/
npm run preview  # serve dist/
```

### Editorial workflow

This site uses [deskwork](https://github.com/audiocontrol-org/deskwork) for editorial calendar and review. See `CLAUDE.md` for installation and workflow.
